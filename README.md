# work-tri-layer

AI 重定义「什么算工作」的应对技能：人的价值从「我会做」迁移到「我能让 AI 做、能判断它做得对不对、能伺候好 AI 伺候不了的人」——把工作拆三层（可替层/指挥层/判断层）重排时间，跑 AI 教练四步闭环，攒提示词库/验收清单/翻车记录三件资产，往「伺候人」侧加仓，一句话筛机会，90 天实验验证。

一句话：**未来 5 年的工作，一半是「伺候 AI」，一半是「伺候人」，夹在中间的那层重复性脑力劳动被抽空了。**

## 方法论底座

- 奥卡姆剃刀主题：人社部新职业名单不是新闻，是官方版产业趋势报告——AI 不是消灭工作，是重定义「什么算工作」
- 三刀剃法：具体岗位名→「产业走到哪一步岗位就长出来」的规律；焦虑叙事→「AI 从聊天进入干活，需要人教/管/验」；猎奇岗位→「钱流向情绪、健康、体验」
- 四条主路：教 AI 干活（机器人训练师/智能体开发员/数字孪生工程师）、帮国家减碳、伺候人（适老化/情绪疗愈/运动数据）、让人开心（文旅 NPC/低空物流）
- 产业节点：有人干→干的人够多→国家转正定标准；八批 121 个新职业精准踩产业升级节点
- 能力迁移：核心能力从「你能做什么」→「你能让 AI 帮你做什么」+「你能判断 AI 做得对不对」
- 人的稀缺：技术能被复制，跟人打交道很难被复制——技术越发达，人的需求越突出
- 入场券非保票：参考正在洗牌的直播带货；该问的不是"怎么找稳定工作"，是"怎么让自己能适应变化"

## 解决什么

| 痛点 | 本技能的做法 |
|---|---|
| "AI 会不会抢我工作"的焦虑 | 三层拆解重排时间：可替层交 AI（一周压一半），指挥层+判断层抢下来——问题不是"会不会被抢"，是"你的时间花在哪一层" |
| 可替层压不下去 | 验收清单先行（3-5 条/任务）+ 打回机制（2 轮上限）+ 压不动诊断（没清单/任务没标准化/翻车率高三因） |
| 省下的时间不知道去哪 | 时间再分配声明：省下的每小时写去向（指挥层/判断层/伺候人侧），下周盘点验证占比变化 |
| AI 产出没人把关 | AI 教练四步闭环：目标（人写）→AI 拆步骤→AI 分步执行→我按验收清单检查；判断层独立于生产者（AI 自查≠判断层） |
| 能力积累停在"学过" | 三件资产只增不删：提示词库（带验证记录）/验收清单（从操作者变教练的关键）/翻车记录（≥3 次重复强制进清单） |
| 职业方向选不准 | 一句话筛机会：伺候 AI（增长快+持续学）/伺候人（增长稳+越老越值钱）/都不沾且重复→撤出；每月 30 分钟扫 JD 技能词（真金白银的证据） |
| 知道但不动手 | 90 天实验：选可迁移方向做最小试点，验收=外部反馈证据（别人用过/买过/反馈过），自嗨实验不算实验 |

## 安装

复制本目录到 `~/.agents/skills/`（或你的 Skill 加载路径）即可。

## 自检

```bash
python scripts/validate.py tests/sample_good.json   # 必须 exit 0
python scripts/validate.py tests/sample_bad.json    # 必须 exit 1
```
