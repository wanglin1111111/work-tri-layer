# 三层拆解 Playbook：每周盘点与压缩执行

> 核心动作：把每周做的事拆成可替层/指挥层/判断层，重排时间。**判据：「做得快」值钱 → 交 AI；「知道该做什么、做得对不对」值钱 → 留自己。**

## 一、每周盘点模板（30 分钟，建议周五做）

```markdown
# 三层盘点 <周次>
## 本周做的事（全部列出来，别漏"杂活"）
| # | 事项 | 周耗时(h) | 归层 | 归层理由（一句话） |
|---|---|---|---|---|
| 1 | 写周报初稿 | 2 | 可替 | 做得快值钱，模板化 |
| 2 | 定下季度 OKR | 1 | 指挥 | 定目标，拍板必须是我 |
| 3 | 审 AI 生成的方案 | 1.5 | 判断 | 做得对不对值钱 |
| 4 | 整理销售数据 | 2 | 可替 | 整理数据，纯搬运算 |
| 5 | 客户访谈+翻译需求 | 3 | 伺候人 | 模糊人话→清楚任务 |

## 层占比（对比上周）
可替层：__h（__%）→ 目标逐周下降
指挥层：__h（__%）→ 目标逐周上升
判断层：__h（__%）→ 稳定或上升
伺候人侧：__h（__%）→ 目标逐周上升

## 本周可替层切换进度
| 事项 | 原耗时 | 现耗时 | 验收清单 | 状态 |
|---|---|---|---|---|
| 周报初稿 | 2h | 0.5h | 3 条 | 已切换 |
```

**判据**：盘点表里"归层理由"列空着的行 = 还没想清楚的事，这周必须补（归层想不清楚 = 三层是假的）。

## 二、归层判据与常见误判

### 归层三问（按顺序问）

```
Q1：这件事的价值在"做出来"（快、全、便宜）还是"做对"（方向、取舍）？
  做出来值钱 → 可替层候选
  做对值钱 → Q2
Q2：这件事是"决定做什么"（目标/任务/标准）还是"判断做得对不对"（结果/质量/交付）？
  决定做什么 → 指挥层
  判断对不对 → 判断层
Q3（伺候人侧单列）：这件事的核心对象是人（需求/情绪/信任）吗？
  是 → 伺候人侧（不在三层内，单独计数，目标上升）
```

### 常见误判（validate.py 会拦的）

| 误判 | 为什么错 | 正确归层 |
|---|---|---|
| "定目标"→可替（让 AI 帮我定计划） | 目标是指挥层的核心——AI 只能给候选方案，拍板权交出去 = 指挥层丢了 | 指挥层（AI 出候选，人拍板） |
| "检查"→可替（让 AI 自查） | 判断层必须独立于生产者；AI 自查 = 自产自销，系统性盲区查不出 | 判断层（人/独立上下文检查） |
| "写验收标准"→可替 | 验收标准就是判断层的工具——标准是谁定的，判断权就是谁的 | 指挥层（标准要人写，清单可让 AI 起草初稿） |
| "沟通"→可替（让 AI 写邮件） | 写邮件是可替，但"沟通该不该说、说什么分寸"是伺候人侧 | 伺候人侧（AI 写初稿，人定分寸） |
| "拆任务"→可替（AI 拆得又快又好） | 拆任务是指挥层；AI 拆完人必须确认/改，照单全收 = 把指挥权外包 | 指挥层（AI 拆，人确认） |

**记忆钩子**：可替层 = 手；指挥层 = 脑（决策）；判断层 = 眼（质检）；伺候人 = 心。手可以外包，脑眼心不能。

## 三、可替层一周压缩计划

```
D1  列清单：可替层全部事项 + 每项周耗时（用上周盘点表，不凭记忆）
    → 算出可替层总耗时 T0
D2-3 配工作流：每项配 提示词（从提示词库取或新建）+ 验收清单（3-5 条，没有先写）
    → 没配完工作流的事项 = 这项还不能交 AI，别硬交
D4-5 并行跑：AI 做 + 人做（同一任务双轨），记录各自耗时与质量
D6  对比验收：AI 产出过清单的 → 可切换；不过的 → 进翻车记录，人做
D7  切换+算账：正式切换项的时间从盘点表移除；
    验收数字：可替层总耗时 T1 ≤ 0.5 × T0（用 D1 的 T0 算，不用"感觉快了"）
```

**压不下去的诊断**（T1 > 0.5×T0 时按序查）：
1. 验收清单缺/太粗 → AI 产出没人验收 = 返工 = 双份活（回 D2-3 补清单）
2. 任务本身没标准化（每次都不一样）→ 这项不该进可替层，重新归层（可能是指挥层）
3. AI 翻车率 >30% → 提示词没验证够，回 ai-coach-loop 跑 2 轮闭环再切换
4. 三项都不是 → 这项 AI 当前真做不了，留人做并标记（不是失败，是边界）

## 四、时间去向声明格式（强制）

省下的时间不声明去向 = 被碎片吃掉（刷消息、临时杂活），三层结构名存实亡。

```markdown
# 时间再分配声明 <周次>
本周可替层省下：__ h（T0 - T1）
去向（必须写满 100%）：
  指挥层：+__ h（具体做什么：把 __ 事项的验收标准写清楚）
  判断层：+__ h（具体做什么：对 __ 事项增加 __ 条检查）
  伺候人侧：+__ h（具体做什么：承接 __ 访谈 / __ 协调）
下周盘点验证：三层占比是否按声明变化（没变 = 声明是假的）
```

**判据**：下周盘点表里三层占比没按声明方向动 = 声明没执行，重写；连续两周不动 = 碎片在吃时间，需要物理隔离（固定时段做指挥层/伺候人侧的事，不是"有空就做"）。
