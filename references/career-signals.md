# 职业信号解读：名单怎么读、机会怎么筛

> 核心：人社部新职业名单**不是新闻，是一份官方版产业趋势报告**。它的价值不在于"有哪些新岗位"，在于三条规律 + 一个筛选器。

## 一、名单的三条规律

### 规律 1：产业成熟信号（岗位是长出来的，不是设计出来的）

```
有人干 → 干的人够多了 → 国家转正、定标准、开培养
（民间自发）   （规模到阈值）    （官方认证 = 产业节点）
```

**读法**：新职业出现 = 该产业已过"有人干"阶段、进入"规模化"阶段。看到名单里的岗位，问的不是"我该去吗"，而是"这个产业走到了哪一步"——刚转正的（第一批）红利在、竞争少；多批都出现的（成熟产业）红利薄、竞争大。

### 规律 2：AI 从聊天到干活，催生"教/管/验"岗位

AI 自己搞不定真实世界的复杂性（机器人摔跤、拿碎水杯、卡电梯）→ 需要人**教它、管它、验它**。

```
名单里一大半是"教 AI 干活"的：
  机器人训练师（教）、智能体开发员（管）、数字孪生工程师（验/建模拟）
这不是"AI 替代人"，是"AI 派生人"——替代发生在 AI 能力覆盖到的重复环节，
派生发生在 AI 能力覆盖不到的复杂环节。
```

**读法**：看到 AI 相关新岗位，先分清它是"教/管/验"哪一类——三类的技能半衰期不同（见下方组合策略）。

### 规律 3：钱从物质流向情绪、健康、体验

物质消费饱和 → 预算重新分配 → "伺候人"的职业（适老化改造、情绪疗愈、运动数据）与"让人开心"的职业（文旅 NPC、低空物流体验）批量出现。

**读法**：这类岗位的增长不依赖技术突破，依赖人口结构与消费结构——所以"越老越值钱"（积累的是对人的理解，不是对工具的理解）。

## 二、JD 技能词扫描法（每月 30 分钟里的 20 分钟）

比趋势文有用的原因：**岗位是真金白银在招人**，JD 是公司愿意付钱的证据。

```
扫什么（两类，各 10 分钟）：
1. 新岗位名称：本月新出现的职位名（同名 ≥3 家公司在招 = 真需求，不是试水）
2. 技能词频：同一个技能词在 ≥5 份 JD 里反复出现 = 正在被定价的能力
   记录格式：<技能词> <出现次数> <出现在哪类岗位> <月薪区间>

判读（技能词的三种信号）：
  出现且薪资上升 → 正在被稀缺化（值得学的方向）
  出现但薪资持平/下降 → 正在被普及化（学了也只是入场券）
  消失（上月有这月无）→ 被工具自动化了（别投了）
```

**与三层拆解的对接**：扫出的"正在被稀缺化"技能词 → 对照你的三层盘点：
- 落在你的判断层/指挥层 → 加深（这是护城河方向）
- 落在可替层 → 确认该层该交 AI（技能在被工具吃掉 = 你留着它 = 双输）
- 落在伺候人侧 → 加仓候选

## 三、四条主路对照（34 个新职业的分类）

| 主路 | 例子 | 增长特征 | 你的切入方式 |
|---|---|---|---|
| **教 AI 干活的人** | 机器人训练师、智能体开发员、数字孪生工程师 | 快，但工具迭代快（技能半衰期短） | 用个人 AI 教练闭环（ai-coach-loop）攒"教/管/验"能力，不追单工具 |
| **帮国家减碳的人** | 可持续发展规划师、微电网管理员 | 政策驱动，稳定但门槛高（专业背景） | 非专业背景者：从"翻译层"切入（把政策语言翻译成企业能执行的方案） |
| **伺候人的人** | 适老化改造设计师、情绪疗愈师、运动数据分析师 | 稳，越老越值钱 | 选一项可交付能力（需求翻译/共情/现场交付），做成职业身份 |
| **让人开心的人** | 沉浸式文旅 NPC、低空物流员 | 体验经济，项目制 | 低频切入：项目制合作，不全职押注 |

**组合策略（一个人可以同时走两条路）**：
```
主业（伺候 AI 侧）：用 AI 教练闭环做你的核心业务（快，养现金流）
副线（伺候人侧）：每周固定 2h 投一项"伺候人"能力（稳，攒长期资产）
判据：主业的收入 + 副线的"交付证据"（上个月交付了什么）双增长
危险信号：副线连续 2 个月没有交付证据 = 停了，重启或换能力项
```

## 四、入场券非保票（名单的正确预期管理）

```
名单给你的是入场券（这张牌有资格上桌），不是保票（上桌必赢）。
证据：正在洗牌的直播带货——2020 年是风口职业，2026 年在洗牌。
新职业的平均寿命：风口型 1-3 年 / 产业型 5-10 年 / 结构型（伺候人）10 年+
判断一个岗位是哪种：
  风口型：靠单一需求爆发（流量/补贴/政策窗口），无技术壁垒
  产业型：踩在产业升级节点（规律 1），有技能壁垒
  结构型：踩在人口/消费结构变化（规律 3），壁垒是对人的理解
应对：
  风口型 → 赚快钱可以，不押职业（随时撤出，见 SKILL 第 6 步）
  产业型 → 投技能（教/管/验），工具换了技能还在
  结构型 → 投积累（对人的理解），时间站在你这边
```

## 五、"不稳定是常态"的操作含义

名单里 34 个职业，五年前一个都不存在。所以：

```
✗ 问法：怎么找一份稳定的工作？（稳定 = 不变的工作，这个市场不产出了）
✓ 问法：怎么让自己变得能适应变化？（稳定 = 你的可迁移能力持续更新）

"适应力"的构成（可盘点，不是口号）：
  1. 提示词库/验收清单/翻车记录在增长（AI 教练资产 = 对 AI 的适应力）
  2. 三层盘点每周在做（知道自己在哪一层 = 对工作的适应力）
  3. 伺候人侧有交付记录（对人的理解在积累 = 对结构的适应力）
  4. 90 天实验在跑（真实反馈在进 = 对方向错判的纠偏能力）
四项每月盘点一次；任何一项连续 2 个月停滞 = 适应力在衰减，该补了。
```
